## 重新生成

```bash
# 1. 启动本地服务
npm run build
npm start

# 2. 录屏（需要本机 Chrome）
node _research/record-new-demo.mjs

# 3. 重新调用阿里云片头/片尾（会使用账号额度）
bl video generate --model wan3.0-video --prompt "..." \
  --resolution 720P --ratio 16:9 --duration 5 --watermark false \
  --download 提交材料/ai-video/intro.mp4
```

> `AHOLO_API_KEY` 只保存在服务端 `.env`，没有进入视频、字幕或本说明。
