# 小红书发布说明

## 要发什么

- 图片：`01-cover.png` → `02-four-exhibits.png` → `03-five-stages.png` → `04-workshop.png`
- 标题和正文：直接复制 `小红书文案.txt`
- 必带话题：**#Aholo黑客松**

## 发布步骤

1. 打开小红书 App，点“发布” → “图文”。
2. 按顺序上传 4 张图（都是 1080×1440，3:4）。
3. 标题填：`我让一只杯子，自己长出了腿`
4. 正文粘贴 `小红书文案.txt` 中“如果一只杯子……”到最后的全部内容。
5. 确认正文里带 **#Aholo黑客松**，再发布。
6. 发布后点笔记右上角“分享” → “复制链接”。
7. 把链接粘贴到报名页的“社交媒体发布链接”输入框，提交。

## 注意

- 每件作品只能登记 **一个** 小红书链接，选最终要展示的那篇。
- 结果公布前笔记要保持公开，不要设为仅自己可见或删除。
- 正文不要放 `127.0.0.1` 本地地址、API Key 或账号信息。
- 如果之后有公网 Demo，可以再补在评论区或正文里；现在这版不依赖外链。
