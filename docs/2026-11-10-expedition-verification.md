2026-11-10

## 已交付
- 默认入口为三环境、每关两次机会、最多六代的进化挑战。
- 12种突变使用明确的能力、原用途代价和结构位替换规则；每次三选一。
- 三种联动具有能力增益、模型行为和设备端发现图鉴。
- 完整成功/失败结算、新种子重开、原种子复玩、分享状态重放。
- 统一模型坐标、按语义附着、主体几何变形、接触连接、表面菌丝与按完整形态取景。

- 原32器官自由实验在 ?sandbox=1；旧进化树在 ?tree=1；旧分享兼容。
- 桌面与窄屏布局；加载失败重试、弹窗键盘焦点与关闭支持。

## 验证结果
- npm run build：通过，生产产物已更新，现有8787本地服务可直接访问。
- npm run test:expedition：通过；覆盖1605条成功、1714条失败路径；同路径确定性、各阶段分享、非法数据、重复结算、三组合联动、四原型、坐标与接触面、主体变形均通过。
- 专项回归：带偏移/缩放的源模型居中落地；压缩GLB的Int16顶点先转换为Float32再变形，避免溢出尖刺。
- npm run test:engine：400次旧引擎运行，确定性不一致0、非法数值0、重复候选组0。
- npm run test:play：浏览器真实点击完成成功/失败两局；重播不增加代数；分享重放、重开、取消重开、四祖先切换、图鉴、390宽度与手机试验通过；页面异常0。
- scripts/expedition-model-qa.mjs：四祖先×三联动共12种形态均加载与截图，页面异常0；已逐轮检查并修正错误朝向、遮挡和尖刺。
- scripts/expedition-resilience-qa.mjs：模拟批量器官加载失败后重试恢复；同页分享切换；320/390/768宽度无横向溢出；32器官沙盒与旧树入口保留。
- 截图：_research/expedition-initial.png、_research/expedition-mutation.png、_research/expedition-qa/。

## 表现边界
试验由确定性规则驱动，不是物理仿真。主体变形、程序化连接和器官协同行为已实现；不支持任意两个GLB之间的无缝拓扑融合。旧自由实验里的跨物种拼接明确标为实验功能。没有创建在线生成任务，没有新增依赖；原文件备份在 _research/before-expedition/。
