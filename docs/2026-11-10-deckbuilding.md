# 卡牌构筑改版

方向：以用户要求的卡牌构筑和自由选择重做默认玩法，沿用已完成的Lux3D和自然贴合表现。

- 32器官+10动作牌；六套可编辑起始牌组，10至20张，单卡最多两份。
- 抽5、每回合3基础能量、弃牌重洗；可保留1张手牌。机体容量7，主动拆解，重复器官升级而非强制换件。
- 三类环境轮换意图，存在控制、机动逃离、连续抵抗、独立供能等胜利路线；取消每关两选及六代硬上限。
- 信号、浮游、扎根、动力、蓄能、反击、寄生、回收等流派有被动联动。
- 每场奖励6选至多2，可跳过；DNA可用于升级、删牌和恢复。
- 默认改构筑模式；旧挑战/沙盒/进化树和分享链接保留入口。
- 独立纯函数规则、状态与资源守恒检查、真实浏览器完整玩法检查。

## 验证结果

- `npm run build`：类型检查与正式构建通过。
- `npm run test:deck`：6套预设×8种种子完成48局；覆盖机动脱离、借风位移、控制权归零、连续抵抗、独立供能五种结果。另验证不出牌会失败、满容量拒绝而不强拆、留牌、器官强化、战后选牌上限、删牌/升级和分享状态恢复，逐行动检查卡牌守恒。
- `npm run test:deck-ui`：真实页面36次行动完成三场、两次战后选牌和改造；验证刷新保存、牌库筛选/编辑、留牌、牌堆弹窗、320/390px布局，未出现页面脚本错误。
- `npm run test:attachments`：原有接触面、器官间隙、主体变形、贴合材质与接缝检查通过。
- `npm run test:engine`：旧进化树400条确定性路径通过。
- 页面记录：`_research/deck-qa/`。规则胜负仍是可解释的卡牌系统；3D展示其形态与行为，并非物理模拟。
