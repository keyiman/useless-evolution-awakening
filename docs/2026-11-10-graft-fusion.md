# 器官根部一体化与材质衔接

2026-11-10

用户要求在已修正位置关系的基础上继续提高自然贴合程度。

## 实施
- MountedOrgan 取消统一的灰色套筒、细杆、底板和开口横梁。
- 新增 graftGeometry：使用连续环形截面构建圆滑根部，侧面根部逐点投射到真实主体网格，薄面板的过渡体受后表面平面约束，避免穿出电池片。
- 新增 graftMaterial：采样接触处的原材质，保留主体贴图与PBR粗糙度、金属度；过渡面沿用主体UV。器官背部有限范围逐渐转入主体材质，前部功能细节保留。
- 太阳能板完整保护蓝色电池片；裁去太阳能板、摄像头的不适用落地支架。侧面器官适度嵌入主体，避免仅在外侧相碰。
- 底部套接加深，圆滑过渡收薄，代替原先的独立平板边界。
- 无密封盖时，杯/桶顶部附肢从真实口沿生长，取消跨越空口的金属横条。
- 主挑战和自由实验共用实现；缓存GLB几何、原材质保持不变，实例几何与材质有独立释放逻辑。
