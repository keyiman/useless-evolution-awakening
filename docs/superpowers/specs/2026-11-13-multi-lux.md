# 多物品Lux3D动态进化

用户选择：Lux3D生成模型为主体，当前杯子效果作为动画参考。保留四个真实GLB主体和原有材质/UV，不以程序化替代品冒充Lux3D。

四件展品各五阶段：杯（原物/苏醒/行走/感知/绽放）、椅（原物/苏醒/迈步/探身/舒展）、伞（原物/苏醒/浮游/感风/舒展）、桶（原物/苏醒/挪动/感知/开合）。新增物品切换器，分别保存进度；切换取消当前播放并加载对应展品。所有物品继续共用柔和背景、播放/暂停/重播和阶段回看。

现有GLB均为单网格且无骨架/动画。按规范化几何分区为现有主体增加GPU形变：椅腿分四区迈步、椅背弯曲；伞面径向呼吸/扇区波动、伞柄摇摆；桶上盖按铰链旋转、桶身收放。杯子保留新增关节足/触角/冠瓣，但用真实Lux3D杯身替换程序化杯，并让原杯把连续收回。注明主体来源与附加动画，不声称GLB自带动画。

执行与验证：先建立资源来源/独立进度/每展品五阶段检查；增加资源规范化与分区动画；接入选择器和镜头；真实浏览器检查四展品各阶段、切换/暂停/重播/刷新、手机布局、所有模型请求成功及无WebGL报错。
