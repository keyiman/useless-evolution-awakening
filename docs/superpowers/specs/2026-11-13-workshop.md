# 自主进化工作台

用户已批准：独立工作台，输入第一代物品提示词生成模型，手写或选建议后修改变异，从旧节点分支，每代保留模型和提示词；不改变四件预制展品。

实现：`?create=1` 独立页面。React本地保存节点树/当前选择/未完成任务；通过现有服务端Aholo适配器提交、轮询、缓存GLB。接口密钥只在服务端。异步任务元数据持久化、同提示词去重；刷新恢复，不自动伪造模型。提示词演化为文字继承，不保证几何精确编辑；静态生成模型与后制轻呼吸/浮游动作明确分开。

用户输入首代名称与外形；选中一代后填写下一次变异，可点击建议填入后编辑；提交前可看最终提示词。谱系节点可切换，失败保留文字并支持重试，暂时查询失败可继续等待；正在生成时保留上一代模型并明确标记。可下载当前GLB、开始新作品；与预制展进度及资产映射独立。

验证：节点/提示词/分支/存储检查；服务端真实缓存与同任务恢复检查、失败路径；浏览器提交/等待/失败/重试/分支/刷新/模型预览/手机布局测试；只用已有完成任务验证真实Aholo凭据，不未经必要生成新付费测试模型。
