# 活过来的杯子：3D进化与动作展示

用户已确认：以3D观感为核心，删除挑战机制，每次进化完成自动演示新动作。

五个连续阶段：原物、苏醒（三足萌芽与呼吸）、行走（三只关节足交替踏地）、感知（杯把分化成前探触角，转向探查）、绽放（杯口六片冠瓣张合）。没有卡牌、血量、胜负、环境试验或旧模式入口。

物品始终保持可识别的杯形，使用统一陶瓷、软连接与金属关节材质；新器官从主体生长，不贴现成零件。关节足按三维两节逆运动学解算，脚尖有接地与抬脚相位。触角以分段关节摆动；冠瓣有独立开合。动画区分进化过渡、自动动作演示、安静观察，支持重播、暂停、回看任一阶段、重置；进度自动保存。

页面为模型优先的大幅展台、底部五阶段时间线、小型状态说明与主操作，适配手机。旧查询参数及分享地址统一落到新展示，不再加载旧玩法。

验收：所有阶段连续无突跳，三足解算长度稳定、脚尖不穿地；动画完成自动展示，重播和暂停生效，手机无整体横溢；真实浏览器检查五阶段与画面。
