项目摘要         本项目拟开发一款由随机种子驱动的 3D 物品进化游戏。玩家选取水杯、椅子、雨伞或垃圾桶
等日常物品，自由输入随机种子，在“机械增生、功能反转、跨物种杂交、递归套娃、寄生维护、器官
独立”等规则作用下产生多代分支子代。每一代同时记录物品基因、功能变化与几何结构，并借助 Aholo
Lux3D 生成可旋转、可观察的三维模型。进化既可能暂时改善物品功能，也可能由于看似合理的连续升
级最终诞生完全无用的荒诞机器。作品以可复现的规则树、不可预先猜测的突变、可见的形态变化和可
直接体验的失效演示为核心特色。

    定位约束：“无用”须有可展示的结构原因；“进化”须发生可识别的 3D 形态变化；“随机”须可
    重放规则决策；
          “分支”须允许回溯；
                   “核心技术”须真实使用 Lux3D。该文档是策划与调研书，不

3.2 创作原则
  1. 无用性可解释：每次失效应能指出一个结构冲突或新增操作成本。
  2. 3D 特征必须鲜明：关键变异至少改变轮廓、部件、连接方式或可动关系之一。
  3. 允许眼前一亮：中间世代可真正改善性能，随后发生意外冲突；不强制实用性单调下降。
  4. 保留祖先记忆：默认保留两项以上祖先身份标记；稀有彻底变形须在谱系和说明中明确记录。

4.2 操作界面需求
页面分为四区：中央 3D 标本室展示 GLB，支持旋转、缩放、复位与对比；右侧基因面板展示继承部件、
突变原因、原始功能与本代功能；下方谱系区显示代际、候选和跨枝关系；操作区提供进化、随机/定向
突变、返回祖先、保存、分享和测试。手机版为上下折叠布局，但桌面版优先。


4.3 三类游戏模式
  1. 自由进化：选祖先与种子，每代抽取三个候选方向，只生成选定节点的高质量 3D 模型。
  2. 无用性试验场：在预设场景触发“喝水、坐下、挡雨、投垃圾”等简单动作，由游戏规则决定是否成
     功，不虚构真实机械试验结果。
  3. 标本收藏：保存进化树、祖先对照图、基因说明、种子与 3D 文件；允许复制路径继续分叉。


5 核心算法：种子、遗传基因与非单调进化

5.1 基因型与三维表现型分离
节点的基因型包含祖先类别、主要部件、安装关系、保留功能、新增功能、冲突对、材料和运动约束；表
现型包含生成提示词、模型 GLB、参考图、模型坐标标准化信息及测试动作配置。模型生成失败只影响
表现型，不丢失整个谱系。
     节点关键字段包括 nodeId、parentIds、baseObject、generation、worldSeed、ruleVersion、genes、

5.2 “同种子同路径”的可复现实现
设世界种子为 s，当前节点内容哈希为 h，候选槽位为 k ∈ {0, 1, 2}，规则版本为 v，该候选的独立随机状
态定义为
                                         rh,k = PRNG(Hash(v∥s∥h∥k)) .

这样即使玩家先探索另一条分支，也不改变原节点三个候选的结果。seedrandom 可提供可预测的伪随机
序列。[12] 注意保存规则版本、排序策略与基因数据，否则修改权重后旧种子可能失去原含义。
function makeCandidate(parent, slot, worldSeed, version) {

    const key = `${version}:${worldSeed}:${parent.hash}:${slot}`;

    const rng = seedrandom(key);

5.4 进化决策与筛选目标
每个候选以四维标记描述：原始实用性 U 、新颖度 N 、荒诞因果性 A、祖先可辨认度 R。评分用于系统
排序和测试，不是未经验证的物理真实性度量。候选不强制最大化无用性；可采用

                     Q = 0.30N + 0.30A + 0.20R + 0.20D,             D = min{1, |Ut − Ut−1 | + Ct },

其中 Ct 是检测到功能冲突时的附加项。权重为初始设计值，应通过试玩调整。对原始用途确实改善的代
际允许 Ut > Ut−1 ，以产生“合理升级之后意外失控”的体验。

算、形态可观察、过程可比较、结果可出乎意料。若只能输出文字和静态海报，技术定位即不成立；若只
能随机堆叠零件而无明确因果，创意定位也不成立。两者共同满足，才是本项目的参赛竞争力。
