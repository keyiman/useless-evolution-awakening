MCP

Model Context Protocol（MCP） 让 Cursor、Claude Desktop 等 Agent Studio 通过标准协议调用 Aholo 能力。官方包 @manycore/aholo-sdk-mcp 在本地以 stdio 方式运行，底层封装 @manycore/aholo-sdk-* npm SDK。

使用前请先在 快速开始 申请 API Key，并阅读 授权。

MCP、Skill 与 SDK 怎么选​

方式适合谁典型场景
MCP（本页）在 Cursor / Claude 里用对话驱动上传本地文件、提交重建、查任务进度
Skill同上，偏工作流与参数约束复杂 3DGS 流程、SkillHub 一键安装
SDK写业务代码的开发者后端服务、脚本、生产环境集成

MCP 与 Skill 可配合使用：MCP 提供 tool 调用能力，Skill 提供对话策略与业务约束。

前置要求​

  • Node.js ≥ 18
  • Aholo API Key：labs.aholo3d.cn/api-keys

安装​

Cursor​

编辑 ~/.cursor/mcp.json（项目级可用 .cursor/mcp.json）：

{
  "mcpServers": {
    "aholo-sdk-mcp": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@manycore/aholo-sdk-mcp"],
      "env": {
        "AHOLO_API_KEY": "your_api_key_here",
        "AHOLO_REGION": "cn"
      }
    }
  }
}

Claude Desktop​

编辑配置文件（macOS：~/Library/Application Support/Claude/claude_desktop_config.json）：

{
  "mcpServers": {
    "aholo-sdk-mcp": {
      "command": "npx",
      "args": ["-y", "@manycore/aholo-sdk-mcp"],
      "env": {
        "AHOLO_API_KEY": "your_api_key_here",
        "AHOLO_REGION": "cn"
      }
    }
  }
}

保存后重启 Agent / Studio。在 Cursor 中可在 Settings → MCP 查看连接状态。

验证​

AHOLO_API_KEY=your_key npx -y @manycore/aholo-sdk-mcp

未设置 AHOLO_API_KEY 时会提示并退出，属正常行为。

环境变量​

变量必填说明
AHOLO_API_KEY是Aholo API Key
AHOLO_REGION否cn（默认）
安全提示

请勿将 API Key 提交到公开仓库或分享给他人。推荐仅通过 mcp.json 的 env 或本机环境变量注入。

使用说明​

文件上传​

本地文件通过 localPath 传入，SDK 直接读磁盘上传至 CDN，二进制不经过 MCP 协议。

World 重建（scene）​

场景推荐 Tool
单个物体 / 产品 / 手办world_reconstruct_object_from_files 或 world_reconstruct_object
室内 / 房间环拍world_reconstruct_space_from_files 或 world_reconstruct_space
  • 图片重建须 ≥ 20 张（.jpg/.jpeg/.png/.webp）；普通视频 resourceType=video（.mp4/.mov）；Insta360 全景 resourceType=insv（.insv）
  • useMask=true 表示抠图（主体分割）
  • taskQuality 默认 normal；「快速预览」→ low，「高质量 / 专业」→ high

World 生成（Spatial Gen）​

world_generate 用于 AI 生成世界（非多图重建）：

  • 纯文案：只传 prompt
  • 单张参考图：只传 localPath（内部先 upload_asset）
  • 图文组合：prompt + localPath（至多 1 张图）

参考图只接受本地 localPath，不接受外部网络 URL。多图/视频请用 world_reconstruct_*。

长任务​

提交类 tool 默认 wait=false，立即返回 worldId / taskId：

  1. 查进度（推荐）：world_get / lux3d_get_task
  2. 等到完成：world_wait_for / lux3d_wait_for_task（阻塞，可能占用连接数分钟）

可用 Tools​

推荐（scene 已固定）：

Tool说明
world_inspect_local_media只读：分析本地图片/视频
world_reconstruct_object_from_files本地文件 → 物体（model）重建
world_reconstruct_space_from_files本地文件 → 室内（space）重建
world_reconstruct_objectURL → 物体（model）重建
world_reconstruct_spaceURL → 室内（space）重建

通用：

Tool说明
upload_asset上传本地文件，返回 CDN URL
world_generate3DGS 世界生成：纯文案 / 本地单图 / 图文（至多 1 张，走 localPath）
world_get / world_wait_for / world_list查询与轮询 world

Lux3D​

图生/文生 3D 的 version 必填：G1 或 G1-Turbo。faceCount 范围 10000–300000；outputFormat 支持 zip / glb / ply；aiPredictSize 控制尺寸预测。图生 3D 的单图/多视角输入必须二选一。

Tool说明
lux3d_multimodal_to_image多模态生图：prompt 和/或 图片（img URL / localPath）至少一个
lux3d_image_to_four_view图片 URL / 本地图 / 文案生成四张标准视图
lux3d_img_to_3d_from_file / lux3d_img_to_3d / lux3d_text_to_3dLux3D 图生 / 文生 3D（G1 / G1-Turbo）
lux3d_material_transfer参考图材质迁移到 GLB 模型
lux3d_multi_format_exportLux3D ZIP/GLB 导出 USDZ/OBJ/FBX/STL/3MF
lux3d_part_splitGLB 部件拆分
lux3d_articulation_animationGLB + 提示词，关节化与动画
lux3d_humanoid_auto_rig数字人 GLB 自动绑骨
lux3d_humanoid_animation_retarget已绑骨模型的动画重定向（1–10 个预设动作，GLB/FBX）
lux3d_list_tasks分页查询 Lux3D 历史任务，可按状态和时间筛选（筛选不含 6）
lux3d_get_task / lux3d_wait_for_task查询与轮询 Lux3D 任务

当前 npm 包版本：@manycore/aholo-sdk-mcp@1.9.0（依赖 @manycore/aholo-sdk-lux3d@^1.9.0，共 26 个 tools）。任务结果仍可能包含 6（已取消）。

完整说明见 npm 包 README。
